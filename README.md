# Payroll Management System Web

A Java-based web application that helps manage employee information and payroll operations.

## Features
- Employee management
- Salary calculation
- Allowances and deductions
- Payslip management
- Database storage using MySQL

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- MySQL
- Apache Tomcat
- NetBeans IDE

## Project Source Code
[View the source code on GitHub](https://github.com/dharshiniv916/Payroll-Management-System-Web)

## How to Run
1. Install JDK and Apache Tomcat.
2. Set up MySQL and create the required database.
3. Configure the database connection in the application.
4. Deploy the project WAR file to Tomcat.
5. Start Tomcat and open the application in your browser.
